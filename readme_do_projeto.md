# 📐 Simulador Interativo do Teorema de Pitágoras

Um projeto educacional web, visual e interativo, desenvolvido para facilitar o ensino e a compreensão do **Teorema de Pitágoras** ($a^2 + b^2 = c^2$).

Através de uma interface gamificada de arrastar e soltar (drag and drop), os estudantes do Ensino Fundamental (9º ano) podem comprovar empiricamente que a soma da área dos quadrados formados sobre os catetos é exatamente igual à área do quadrado formado sobre a hipotenusa.

## ✨ Funcionalidades

* **Interatividade Real:** Os alunos podem arrastar os "quadradinhos" de área dos catetos e encaixá-los perfeitamente no quadrado da hipotenusa.
* **Ternos Pitagóricos Dinâmicos:** Suporte para a visualização de múltiplos triângulos retângulos perfeitos (3-4-5, 6-8-10, 5-12-13, 7-24-25, etc.).
* **Desenho Geométrico Exato:** O triângulo e as áreas são desenhados via código com proporções reais, utilizando SVG e cálculos trigonométricos.
* **Design Responsivo:** Funciona perfeitamente em computadores (mouse) e em dispositivos móveis (touch screen/celulares).
* **Sistema Anti-Bug:** As peças arrastadas retornam automaticamente para seu local de origem caso sejam soltas em um local incorreto.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando apenas tecnologias web nativas (Vanilla), sem dependência de frameworks externos pesados:

* **HTML5:** Estruturação semântica da aplicação.
* **CSS3:** Estilização visual, responsividade (Grid e Flexbox) e tipografia.
* **JavaScript (ES6):** Lógica matemática, trigonometria para angulação da hipotenusa, manipulação do DOM e detecção avançada de eventos de ponteiro (Pointer Events) para compatibilidade com touch e mouse.
